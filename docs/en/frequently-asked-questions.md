## Does this repository contain the complete brokerage source code?

This material contains the project presentation, documentation and images. Code delivery and licensing terms are defined in the proposal.

## Are the images an interactive demo?

They are screenshots of the landing page and demo terminal. Ask on WhatsApp whether a demonstration is available through a link.

## Is the terminal a demo account?

Yes. The supplied screen identifies the account as demo.

## Can I customize it with my own brand?

Customization of identity, text, languages and user experience can be included in the contracted scope.

## Which APIs and brokers are already integrated?

This presentation does not publish a tested integration matrix. Specify the providers and APIs you need for technical evaluation.

## Will the stack use Next.js, FastAPI and Supabase?

The stack is defined in the technical proposal according to requirements. Their presence in the glossary does not establish that the implementation uses them.

## What are the price and delivery time?

Price, timeline and support depend on scope, integrations and deliverables. Request a proposal with your project details.

## What should I send to request a quote?

Your goals, features, integrations, visual references and expected timeline. Passwords and API keys are not needed for the initial request.

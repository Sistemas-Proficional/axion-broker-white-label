This page separates the presented interface from the requirements that need to be defined for a commissioned project.

## Available visual reference

- AXION-branded landing page.
- A terminal marked as a demo account, displaying BTC/USDT on a candlestick chart.
- Amount, expiration and direction controls; wallet, history and tool menus.

## Customization to define

- Visual identity, copy, languages and navigation.
- Client area and registration flows based on requirements.
- Dashboards, reports, permissions and administrative processes to commission.

## Integrations to evaluate

- Market data: provider, assets, availability and API documentation.
- Execution and orders: rules, test environments and expected behavior.
- Payments: provider, methods, webhooks and reconciliation criteria.
- Authentication and verification: providers, flows and project responsibilities.

## Delivery plan

- Record agreed features and integrations in the proposal.
- Define tests, acceptance criteria and the delivery environment.
- Agree on installation, technical documentation, code access and support.
- Select the stack after evaluating requirements; screenshots cannot confirm the implementation.

Technology and platform names appear in the glossary to organize requirements. API, broker and provider compatibility is assessed individually.
